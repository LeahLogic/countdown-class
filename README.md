
# Countdown Class

A simple countdown application built with React using a class component.

## Features

- Starts counting from 100
- Decreases the number by 5 with each button click
- Stops counting at 0
- Clean and responsive design

## Technologies

- React
- JavaScript
- CSS
- Vite

## React Concepts Practiced

- Class components
- State
- setState()
- Event handling with onClick
- Conditional statements

## How It Works

Click the "Decrease by 5" button to reduce the displayed number from 100 to 0.
